# RUGO LEATHER Storefront

This is a premium, **single‑page Next.js storefront** for RUGO LEATHER. The experience has been tailored as an editorial single-page application (SPA) with dedicated sections (cinematic hero, product lookbook, heritage story, and bespoke services). Every call‑to‑action dynamically generates pre-filled messages and points directly to the client's WhatsApp number.

The codebase is minimal but built with maintainability and high-end design in mind: a centralized config, dynamic WhatsApp message routing, a scroll-responsive transparent navbar, smooth Framer Motion animations, and easy-to-update components.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open http://localhost:3000 with your browser to see the result.

You can start editing the page by modifying app/page.tsx. The page auto-updates as you edit the file.

This project uses next/font to automatically optimize and load Playfair Display, giving the brand its signature editorial serif look.
